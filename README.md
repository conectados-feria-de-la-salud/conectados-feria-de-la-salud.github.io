# Pasaporte de salud — pantallas de los voluntarios

Generado por `docs/generar-sitio.js`. No se edita a mano: se cambia el código en
`apps-script/` y se vuelve a generar.

Los datos no están acá: cada pantalla le manda los pedidos a la app de Apps Script,
que verifica el PIN de cada estación y guarda todo en la hoja de cálculo.
